# Pandora Business Model

## Core Principle

The Pandora Runtime (Core) is always free and open source.
The value is not the kernel — it is the ecosystem.

## Revenue Streams

1. **KUBER Palace Marketplace** — 10-20% platform fee on Genes, Domain Packs, Personalities, etc.
2. **Enterprise Edition** — Private Palace, SSO, LDAP, compliance, enterprise support.
3. **Hosted KUBER Palace (SaaS)** — Cloud-hosted registries, benchmarks, collaboration.
4. **AI Compute Marketplace** — Decentralized GPU contribution and revenue sharing.
5. **Domain Packs** — Complete ecosystem bundles (49-99).
6. **Certified Harnesses** — Security-reviewed, benchmarked, signed. Certification fee.
7. **Benchmarks as a Service** — Professional model analytics reports.
8. **Training Platform** — Dataset and evaluation pack marketplace.
9. **Consulting Marketplace** — Platform fee on matched engagements.
10. **Hiring** — Verified-skill recruitment platform.
11. **Enterprise Support** — 24/7, architecture review, migration.
12. **Hosted Models** — Cloud inference rental.
13. **Model Benchmark Observatory** — Continuous per-domain model scoring.
14. **Premium Personalities** — Reasoning profile marketplace.
15. **Premium Domain Memory Packs** — Specialized memory ecosystems.
16. **Pandora Academy** — Courses and certifications.
17. **Premium TUI Themes** — Community/paid themes.
18. **Hardware Partnerships** — Pandora Ready certification.

## Never Monetized

Runtime, core architecture, constitutional kernel, basic CLI/TUI, local execution.

## Phased Plan

1. Open Source Growth (free everything, community building)
2. Marketplace (paid packs, creator revenue sharing)
3. Enterprise (private Palace, org management, compliance)
4. Platform (hiring, consulting, compute, training)

## Constitutional App Store

Every artifact carries structured metadata. Users browse by capability, not name.
