# Greeting Skill

A friendly skill that responds to greetings.

## What it does

When a user says hello, the agent responds with a warm greeting
appropriate for the time of day and context.

## Usage

Just say "hello" or "greet me" — the agent will pick it up.

## Example

User: "Good morning!"
Agent: "Good morning! Ready to get started?"
