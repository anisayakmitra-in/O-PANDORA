# Code of Conduct

We want O-PANDORA to be a project where people can do good work without dealing with needless friction.

## What helps

- Write clear, focused issues and pull requests.
- Give feedback that is specific and actionable.
- Treat disagreements as normal. Work through them.
- Respect different time zones, skill levels, and backgrounds.

What does not help

- Personal attacks, insults, or slurs.
- Harassment in public or private channels.
- Publishing someone else's private information.
- Disruptive arguments that derail the work.
- Dismissing people because of their experience level.

## Scope

This applies in project spaces: GitHub, discussions, chat, events, and anywhere someone is representing the project in public.

## Reporting

If you see behavior that violates this code, contact the maintainers at [REDACTED]. Reports are handled confidentially.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code. Repeated or severe violations can result in a temporary or permanent ban from project spaces.
